# เปิดระบบอีกครั้ง สัปดาห์ 9–15 พ.ย. 2026 (2026-W46)

ระบบหยุดตั้งแต่ 19 ต.ค. งานรอบใหม่เริ่มที่วันที่จริง ชื่อสัปดาห์ตามเลขสัปดาห์จริง (W46) ทำตามลำดับ ข้อที่ขึ้นต้นด้วย "ตรวจ" คือสิ่งที่ต้องเห็นก่อนไปข้อถัดไป

## ก่อนวันเปิด

1. **พื้นที่ Drive.** GitHub → Actions → **Drive usage** → Run workflow แล้วเปิดหน้า Summary ส่งตารางให้ Claude ทำรายการลบ รูปส่งลูกค้าใน Exports เก็บไว้จนลูกค้ายืนยันว่ามีสำเนาแล้ว
2. **คิวจะยาวขึ้นแค่ไหน (ไม่บังคับ).** Neon → SQL Editor → วาง `docs/queue-impact-batch2.sql` → Run แล้วส่งผล
3. **โฟลเดอร์สัปดาห์ใหม่ใน Drive.** GitHub → Actions → **Prepare week** → Run workflow (ค่าเริ่มต้น `2026-11-09`) ได้ `Inbox/Week 9-15 Nov/` กับ `Pool/2W`, `Pool/4W` และ 2 W Saver · 2 W Standard · 4 W Standard ถ้า Ops สร้างไว้แล้วบางส่วน ระบบใช้ของเดิม สร้างเฉพาะที่ขาด กดซ้ำได้
   - ตรวจ: log บอก "สร้างใหม่ … · มีอยู่แล้ว …" และเห็นโฟลเดอร์ใน Drive ให้ Ops วางอัลบั้ม LINE ใน `Pool/2W` หรือ `Pool/4W` โฟลเดอร์ไรเดอร์ระบบเปิดเองตอนจัดกอง

## วันเปิด

1. **Render.** เปิด service ที่พักไว้ (Resume) แล้วเช็คว่า Environment มี `GITHUB_TOKEN` (Actions: write) และ `GITHUB_REPO` ถ้าไม่มี แท็บปิดสัปดาห์และปุ่ม "อ่านรูปเดี๋ยวนี้" สั่งงานไม่ได้
   - ตรวจ: เปิดเว็บแล้วล็อกอินได้ แท็บภาพรวมขึ้น
2. **ล็อก W40 เดิม (28 ก.ย.–4 ต.ค.).** เว็บ → ⚙ → เครื่องมือเพิ่มเติม → หน้าจอเดิม → การ์ดสัปดาห์ 28 ก.ย. → 🔒 ล็อกสัปดาห์ ไม่ต้องลบอะไร ระบบจะไม่อ่านและไม่นับ 29 แถวนั้นอีก
   - ตรวจ: การ์ดนั้นขึ้นว่าล็อกแล้ว
3. **W39 `_พร้อมอ่าน`.** ปล่อยไว้ที่เดิม ไม่กด Move staged (W39 ล็อกแล้ว ระบบไม่เดินเข้าไป)
4. **เปิด workflow.** GitHub → Actions → **Weekly ingest** → Enable workflow และ **Archive runs** → Enable workflow
5. **รอบแรก.** Actions → Weekly ingest → Run workflow → ติ๊ก `force_walk` → Run รอบนี้เดินทุกโฟลเดอร์จริง ไม่เชื่อตัวถาม Drive เพราะระบบหยุดไปนาน
   - ตรวจ: log บอก `2026-W46` และ `error 0` เว็บภาพรวมขึ้นสัปดาห์ 9–15 พ.ย.
6. **Archive runs ครั้งเดียว.** Actions → Archive runs → Run workflow → days = `90` เพื่อเก็บ log ที่ GitHub ยังมีอยู่
7. **หลังจากนั้น** รอบอ่านรันเองทุก 3 ชั่วโมง ถ้ารอบไหนล้ม GitHub ส่งอีเมลแจ้งบัญชีที่กด Enable (ถ้าเปิดการแจ้งเตือน Actions ไว้ใน Settings → Notifications)

## ถ้ามีอะไรไม่ตรง

- รอบอ่านข้ามหมดว่า "มีรอบกำลังรันอยู่": มีรอบเก่าค้าง รอบถัดไปปิดให้เอง หรือรันมือหนึ่งครั้ง
- ปุ่มปิดสัปดาห์กดไม่ได้: ยังมีแถวในคิวตรวจของสัปดาห์นั้น หรือยังไม่ได้กด "ดูแผน" ภายใน 12 ชั่วโมง

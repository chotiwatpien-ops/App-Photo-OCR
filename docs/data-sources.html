VERIFYสมการที่ใช้ตัดสินทุกแถว

ก่อนอนุมัติอัตโนมัติ ระบบบวกเลขจากรูปทวนเองเสมอ:

J (คุณได้รับ) = K (พื้นฐาน) + M (โบนัส+ทิป) + N (เทอร์โบ)
เงื่อนไขอนุมัติอัตโนมัติถ้าไม่ผ่าน
สมการข้างบนลงตัว (±0.01)ป้าย "เลขขัดกัน" → คิวตรวจ
มี booking code และไม่ซ้ำกับที่เคยอนุมัติป้าย "เคยอนุมัติแล้ว/ซ้ำ" → คิวตรวจ (จับสลิปซ้ำข้ามไรเดอร์ได้)
ไม่ซ้ำใน job เดียวกัน + มีวันที่คิวตรวจ

สมการเทียบประกอบ: ยอดผู้โดยสารรวม − ค่าบริการแกร็บ = K (ใช้ทาน ไม่ใช้ตัดสิน)

PAIRINGรูป 2 ใบรวมเป็นงานเดียวยังไง

ชั้นเงื่อนไขใช้เมื่อ
1 · เลขตรงbase/net/ยอดรวมของสองรูปตรงกันรูปปกติ (90%+ ของงาน)
2 · ลำดับไฟล์ + อนุมานรูปล่างอ่านเลขไม่ได้เลย → จับกับรูปบนที่ติดกัน แล้วอนุมาน Kเครื่องฟอนต์ใหญ่ / รูปเลื่อนเกิน
3 · ลำดับไฟล์ + booking codeรูปล่างไม่มี code ติดกับรูปบนที่มี code → คู่กัน (ดึงเฉพาะข้อมูลฝั่งผู้โดยสาร)ทีมยืนยัน: ไรเดอร์วางรูปคู่ติดกันเสมอ
ค่าจากใบแจกแจงครึ่งล่างถือเป็นความจริงสำหรับ K, M, N — ครึ่งบนใช้ยืนยัน J (คุณได้รับ) กับข้อมูลเส้นทาง/ชิพเท่านั้น

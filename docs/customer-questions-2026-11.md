เรียนทีมงาน

ขอบคุณสำหรับ Requirement ชุดใหม่ครับ ก่อนเริ่มใช้กับสัปดาห์ 9–15 พ.ย. ขอยืนยันรายละเอียดตามนี้ครับ

**1. โซนพื้นที่ (Polygon)**

แนบ Google Sheet "Zone Mapping W46" มาให้ครับ ในชีตมีทุกเขตของกรุงเทพฯ และพื้นที่รอบๆ พร้อมโซนที่เราเสนอไว้ รบกวนดูคอลัมน์สุดท้าย ถ้าถูกต้องใส่ ✓ ถ้าไม่ถูกพิมพ์โซนที่ถูกต้องแทน แถวที่มีเครื่องหมาย ? คือแถวที่เราไม่แน่ใจครับ

นอกจากในชีต ขอถามเพิ่ม 3 ข้อครับ

1.1 ชื่อโซนในไฟล์ ให้ใช้แบบไหน
- ชื่อสีตามตารางของทีม: Green / Grey / Orange / Pink / Blue (Pink = Pattaya, Blue = Other)
- ชื่อพื้นที่: City Center / Inner City / Outer Ring / Pattaya / Other
- ชื่อสีภาษาไทย: เขียว / เทา / ส้ม / ชมพู / น้ำเงิน

1.2 สลิปไม่มีพิกัด GPS ระบบจึงแบ่งโซนจากชื่อเขตหรือแขวงในที่อยู่ ไม่ได้ตามเส้นบนแผนที่แบบเป๊ะๆ ยอมรับได้ไหมครับ

1.3 ที่อยู่ที่ไม่อยู่ในเขียว เทา ส้ม หรือพัทยา ทั้งในและนอกกรุงเทพฯ เราจะใส่เป็น Other (สีน้ำเงิน) ทั้งหมด ถ้าต้องการแยกที่อยู่นอกกรุงเทพฯ เป็นโซนใหม่ เช่น "Outside" แจ้งได้ครับ
เราลองกับเที่ยวจริงของ 4 สัปดาห์ (31 ส.ค.–4 ต.ค. รวม 17,707 เที่ยว) Other จะมีราว 2.1% ของจุดรับส่ง เป็นในกรุงเทพฯ 0.7% และนอกกรุงเทพฯ 1.4% ส่วนนอกกรุงเทพฯ มาจาก
- ปทุมธานี (คลองหลวง ธัญบุรี เมืองปทุมธานี) ราว 200 จุด
- นครปฐม (สามพราน พุทธมณฑล) ราว 100 จุด
- สมุทรสาคร (กระทุ่มแบน เมืองสมุทรสาคร) ราว 80 จุด
- ชลบุรีที่ไม่ใช่พัทยา ราว 20 จุด

**2. Driver ID (4 หลัก)**

2.1 รหัสไรเดอร์มีอยู่แล้วไหมครับ ถ้ามี รบกวนส่งรายชื่อพร้อมรหัสมา (ใช้ไฟล์ Name list เดิม เพิ่มคอลัมน์ "Driver ID") ถ้ายังไม่มี เราออกรหัสให้ได้ โดยรหัสของแต่ละคนจะคงเดิมตลอด

2.2 ชื่อเดียวกันคนละประเภท เช่น "ตฤณ Win" กับ "ตฤณ Taxi" ใช้รหัสคนละตัวใช่ไหมครับ

**3. Order ID**

เข้าใจว่า Order ID = Driver ID 4 หลัก + วันที่ (วันเดือนปี) + ลำดับใบเสร็จของวันนั้น 2 หลัก เช่น 0001 + 301126 + 01 = 000130112601 ถูกต้องไหมครับ

3.1 ลำดับใบเสร็จ นับต่อไรเดอร์ต่อวัน เรียงตามเวลาในสลิปใช่ไหมครับ

3.2 Order ID ให้ใส่ที่ไหน
- เป็นคอลัมน์ใหม่ในไฟล์ Excel
- ใช้เป็นชื่อไฟล์รูปแทนชื่อเดิม
- ทั้งสองอย่าง

**4. ส่วนลดผู้โดยสาร (Passenger discount)**

ต้องการให้แสดงเป็นคอลัมน์ในไฟล์ใช่ไหมครับ ตอนนี้ระบบอ่านบรรทัด "ส่วนลด" ในส่วนค่าโดยสารของผู้โดยสารจากสลิปอยู่แล้ว ใช้ค่านี้ได้เลยไหมครับ

**5. ส่วนลดคนขับ (Driver discount)**

หมายถึงยอดไหนบนสลิปครับ ถ้ามีรูปตัวอย่างที่ชี้บรรทัดนั้นจะช่วยได้มากครับ

**6. แคมเปญรายสัปดาห์ (Weekly campaign: 2 set per driver mode)**

รบกวนอธิบายเพิ่มครับ "2 set" หมายถึงอะไร และ "driver mode" แยกตามอะไร (เช่น Win / Home / Taxi หรือ 2W / 4W) ต้องการให้ระบบทำอะไรกับเรื่องนี้ครับ

**7. Saver (need extra week after initial confirmation to access)**

หมายความว่างาน Saver ต้องรอเพิ่มอีก 1 สัปดาห์หลังยืนยันครั้งแรก ถึงจะเริ่มนับหรือส่งได้ใช่ไหมครับ กระทบการนับงาน Saver ของแต่ละสัปดาห์ยังไงครับ
